# OnShape FeatureScript Projects Library

An open-ended development library and workspace for FeatureScript projects built on OnShape's native cloud CAD platform.

## Overview
This repository serves as a centralized, open-ended library housing reusable FeatureScript code, geometric utilities, algorithms, and procedural modeling patterns. Individual FeatureScript sub-projects will be developed as components within this overall library structure over time.

## Requirements Hierarchy
All requirements follow the [Lightweight Development Process](https://github.com/RandyF/lightweight-development-process)
